## 🛠️ What I've built (as of 27 Nov 2026)

### 🧰 Sourcing Hub ·

One connected hub for sourcing every open role, from the first search to the report leadership reads. Whatever you save in one tool shows up in the next.

| Step | | Tool | What it does |
|---|---|---|---|
| 1 · Find | 🔎 | **X-Ray Finder** | One precise X-ray search string for any of 16 networks, with each operator explained |
| 1 · Find | 🧩 | **Boolean Stringer** | Every ready-made search string for a role, wider or tighter |
| 2 · Shortlist | 🧑‍💻 | **Talent Search** | Describe who you want in plain words, search 12 sources, shortlist per role |
| 3 · Work | 🗂️ | **Sourcing Desk** | One role start to finish: brief, target companies, sources, candidates, notes |
| 3 · Work | 📊 | **Workbench** | What's due today, who's waiting on whom, and a board to move people along |
| 4 · Report | 📈 | **Coverage Report** | How far sourcing has gone on every role, with status and a leadership summary |

Plus a team **Dashboard**, an **Open roles** page, a live activity feed and **Fred** 🦊, the hub's mascot guide.
